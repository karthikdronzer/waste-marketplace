# Waste Marketplace

A MERN stack platform connecting industries with byproduct waste to buyers who can reuse it — acting as an intermediary marketplace with a platform fee model.

## Features
- User authentication (JWT-based register/login)
- Password hashing with bcrypt
- Protected routes using custom auth middleware
- Create and browse waste listings
- MongoDB Atlas integration

## Tech Stack
- Node.js, Express.js
- MongoDB, Mongoose
- JWT for authentication
- bcrypt for password hashing

## Status
Backend in progress — frontend (React) coming next.
